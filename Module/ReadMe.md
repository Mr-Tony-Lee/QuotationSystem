# Python 模組說明文件

本目錄包含 `SKDLLPythonTester` 專案的所有核心模組與 UI 元件。以下詳細介紹每個 `.py` 檔案的功能與職責。

## 📁 根目錄模組 (`Module/`)

這些模組構成了應用程式的核心邏輯、數據處理與 API 串接層。

### 📄 `constants.py`
- **定義**: 包含專案使用的靜態資料與全域常數。
- **主要內容**:
    - `StockList`: 定義所有股票代碼與名稱的對照清單。
    - `FutureList`: 定義所有期貨代碼與名稱的對照清單。
    - `Compare_Map`: 定義「期貨」與「股票」的對應關係（例如：台積電期貨 vs 台積電現貨），這是價差計算的基礎。
    - 這些資料以長字串格式儲存，並由 `DataManager` 解析為結構化數據。

### 📄 `data_manager.py`
- **定義**: `DataManager` 類別，負責資料的集中管理與分發。
- **主要功能**:
    - **資料載入**: 解析 `constants.py` 中的字串，建立代碼與名稱的快速查找表。
    - **初始化配對**: 根據 `Compare_Map` 預先建立 `PriceSpreadInfo` 物件池，準備接收報價。
    - **數據更新**: 提供 `update_quote` 方法，是唯一接收 API 報價並更新記憶體中數據的入口。
    - **查詢介面**: 提供 UI 元件（如 Quote 頁面）所需的數據獲取方法（如 `get_market_data_df`）。

### 📄 `logger.py`
- **定義**: `Logger` 類別及全域實例 `logger`。
- **主要功能**:
    - **線程安全日誌**: 由於 Capital API 的事件回調（Callback）發生在非主線程，直接更新 GUI 會導致崩潰。此模組使用 `queue.Queue` 來線程安全地傳遞訊息。
    - **訊息緩衝**: 提供 `process_queue` 方法供主線程定時呼叫，將積壓的日誌訊息安全地寫入 GUI。

### 📄 `models.py`
- **定義**: 應用程式的核心數據模型（Data Classes）。
- **主要類別**:
    - `StockInfo`: 封裝股票的即時行情數據（開、高、低、收、買賣價量）。
    - `FutureInfo`: 繼承並擴充期貨特有的數據（如結算價、未平倉量）。
    - `PriceSpreadInfo`: 這是套利邏輯的核心類別。它組合了一個 `FutureInfo` 和一個 `StockInfo`，並動態計算：
        - **價差 (Spread)**: 計算正價差（期貨賣-股票買）與逆價差。
        - **套利判定**: `ArbitrageDirection` 屬性判斷是否符合「買股賣期」或「賣股買期」的條件。
        - **成本計算**: 計算包含手續費與稅金的總交易成本。
        - **淨利潤**: 計算扣除成本後的預估獲利。

### 📄 `sk_api.py`
- **定義**: `SKClient` 及其相關事件處理類別。
- **主要功能**:
    - **API 封裝**: 包裝群益 API (Capital API) 的 COM 物件 (`SKQuoteLib`, `SKReplyLib` 等)。
    - **連線管理**: 處理 `Login` (登入) 與 `EnterMonitor` (連線) 動作。
    - **事件監聽**:
        - `SKQuoteLibEvents`: 監聽連線狀態改變與即時報價通知 (`OnNotifyQuoteLONG`)。
        - `SKReplyLibEvent`: 監聽系統回報訊息。
    - **數據轉發**: 接收到底層 API 數據後，轉發給 `DataManager` 進行處理，不直接操作 UI。

## 📁 UI 模組 (`Module/ui/`)

這些模組負責圖形使用者介面的呈現，全部基於 `tkinter` 框架。

### 📄 `login.py`
- **定義**: `FrameLogin` 類別（對應「登入」頁籤）。
- **主要功能**:
    - **使用者認證**: 提供 UserID 與 Password 輸入框。
    - **連線控制**: 執行 API 登入與報價連線。
    - **系統日誌**: 整合 `Logger`，顯示即時的系統運作訊息與錯誤回報。
    - **功能按鈕**: 包含清除訊息與匯出日誌功能。

### 📄 `quote.py`
- **定義**: `Quote` 類別（對應「報價來源」頁籤）。
- **主要功能**:
    - **訂閱管理**: 發送 `RequestStocks` 指令向伺服器訂閱商品報價。
    - **即時監控**: 使用 Treeview 表格顯示所有訂閱商品的即時報價。
    - **進階篩選**: 提供強大的篩選器，可針對類型（期/股）、名稱、價格區間、成交量等條件進行過濾，方便使用者觀察特定標的。

### 📄 `information.py`
- **定義**: `FrameInformation` 類別（對應「總整理」頁籤）。
- **主要功能**:
    - **價差監控**: 專注於顯示「期貨」與「對應股票」的配對數據。
    - **差額分析**: 計算並顯示「期-股差額」與「股-期差額」。
    - **特定篩選**: 允許使用者設定差額閾值，快速找出價差過大的配對。

### 📄 `output.py`
- **定義**: `FrameOutput` 類別（對應「輸出」頁籤）。
- **主要功能**:
    - **策略訊號**: 這是系統的最終產出頁面。它根據 `models.py` 的邏輯，篩選出具有**套利機會**的標的。
    - **決策輔助**:
        - 明確顯示「套利方向」（如：買股賣期）。
        - 顯示「淨利潤」與「總成本」。
    - **自動排序**: 自動將淨利潤最高的機會排在最上方，讓使用者能一目了然最佳交易機會。

### 📄 `dialogs.py`
- **定義**: 通用對話框元件。
- **主要功能**:
    - **公告視窗**: `AnnouncementDialog` 用於程式啟動時顯示版本更新資訊、操作說明與注意事項。
    - **使用者體驗**: 支援記住「下次不再顯示」的設定。
